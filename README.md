# ElectroHub

A responsive static electrical-supplies shop website built with semantic HTML, CSS and vanilla JavaScript.

## Pages

- `index.html` — homepage, categories, featured products and testimonials
- `about.html` — shop story, values, team expertise and stats
- `products.html` — 12-product catalog with category filters and live search
- `contact.html` — store details, hours, map placeholder and validated demo form

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step or package installation is required.

## Customize

- Update the business name, contact details, prices and product copy in the HTML pages.
- Replace Unsplash image URLs with your preferred product and shop photography.
- Change the example site domain in `robots.txt` and `sitemap.xml` before publishing.
- The contact form validates and displays a success confirmation in the browser; it does not transmit or store form data.
